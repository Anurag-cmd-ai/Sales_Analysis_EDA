# Sales Data Analysis

## Project Overview
This project involves a comprehensive Exploratory Data Analysis (EDA) of Diwali sales data. The primary objective is to analyze customer purchasing behavior, identify demographic trends, and determine the top-performing products to extract actionable business insights.

## Technologies & Libraries
This analysis was conducted using Python and the following data science libraries:
*   **`pandas`**: For data ingestion, manipulation, and cleaning.
*   **`numpy`**: For numerical and array operations.
*   **`matplotlib.pyplot`**: For structuring and plotting static visualizations.
*   **`seaborn`**: For creating statistical, aesthetically pleasing plots (e.g., KDEs, count plots).


## Key Analyses Performed
* Data Cleaning: Handling missing values and standardizing data formats.
* Demographic Analysis: Examining sales distribution across different customer demographics.
* Product Performance: Grouping data to find the highest-selling items (e.g., identifying the top 10 most sold products based on order volume).
* Visualizations: Generating bar charts and various plots to illustrate sales trends clearly.

## Repository Structure
* Diwali_Sales_Data.ipynb: The main Jupyter Notebook containing the Python code, data visualizations, and step-by-step EDA.

## Conclusion
The analysis highlights key trends in consumer spending during the Diwali season, allowing for data-driven decisions on inventory management and targeted marketing for top-performing product categories.
